# Paxalia Dashboard v4.1.0

## Release focus

**Paxalia Dashboard v4.1.0 — Security, Stability & Administration**

v4.1.0 is the hardening release following the v4.0.0 platform expansion. It preserves the v4 architecture while tightening correctness, security, compatibility, reliability, diagnostics, localization, and presentation.

## Repository milestone

- `858ebd0` — merge `feat/v4-dashboard-complete-fixes` into main with the stated scope of complete security, stability, administration, and polish.
- `3b73c4c` — corresponding hardening feature branch.

## Administration and localization

The release strengthens:

- Django Admin registry and adapters
- ModelAdmin behavior and compatibility
- permissions and query-state handling
- relationships, deletion semantics, and generic forms
- translated-field discovery and normalization
- language-aware Add/Edit flows
- localization workspace behavior
- model identity and translation preservation through package workflows

## Administrator authentication and 2FA

The release hardens the administrator security boundary around:

- password authentication
- mandatory TOTP/recovery verification
- authorized WebAuthn device credentials
- login, 2FA, and device ceremony rate limits
- CSRF protection
- isolated administrator sessions
- private dashboard mounting

It also aligns manual TOTP material and QR enrollment with the canonical device-backed security model.

## Security and reliability

The release improves:

- protected response and cache behavior
- upload rollback/compensation paths
- backup and share-link protection
- multi-site analytics correctness
- bounded database retry handling
- structured logging and payload bounds
- sensitive-field redaction
- sanitized incident context

## Operations and diagnostics

The release also improves:

- server/runtime inspection
- dependency health
- scheduled report validation
- package validation and retry workflows
- API documentation routing
- package identity restoration
- regression coverage across administration, security, and authentication

## Presentation

The v4.1.0 polish line strengthens:

- administrator forms
- localization screens
- authentication states
- logs and settings
- responsive layouts
- RTL behavior
- CSP-safe browser integration
- packaged self-contained frontend assets

## Position in the product evolution

v4.1.0 is the stabilized v4 baseline. The current v5 release adds operational infrastructure on top of that hardened baseline rather than replacing it.
