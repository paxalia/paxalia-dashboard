# Paxalia Dashboard v3.0.0

## Release focus

**Paxalia Dashboard v3.0.0 — Major analytics, security, monitoring, compliance, API, integrations, and reporting expansion**

v3.0.0 is the largest pre-v4 feature expansion in the supplied repository history. A series of focused feature branches were merged into the v3 release line before the `f5a2803` tag.

## Repository milestone

- `f5a2803` — tag/merge for the complete v3.0.0 release.

## Analytics and behavior

The v3 release line added or expanded:

- multi-site analytics and extended event tracking (`bc20911` / `af32c02`)
- API traffic segmentation (`b7f295a` / `8055b74`)
- goals, funnels, segments, campaigns, and chart annotations (`e701162` / `8fca097`)
- cohort retention analysis (`eea3740` / `642cab1`)
- revenue analytics including MRR/ARR, churn, and dunning tracking (`80d52fd` / `f79c51e`)
- anomaly/spike alerts and an in-dashboard notification center (`964a74f` / `fe2f0fe`)
- scheduled email reports and public share links (`06fbe28` / `552fd2d`)
- Paxalia API keys, ingestion, and a documented read API (`909d8f1` / `6c614cd`)

## Monitoring and operational visibility

v3 also expanded the platform with:

- Core Web Vitals and browser JavaScript error tracking (`20a88fb` / `55910c2`)
- scheduled uptime checks, status history, and incident logging (`c896fb1` / `2206a46`)
- real server history, slow queries, queue monitoring, and deployment tracking (`fea2575` / `2483781`)
- bot classification covering search engines, AI crawlers, social previews, SEO tools, and malicious traffic (`86575fc` / `c6ee511`)

## Security and compliance

The v3 line also added:

- Security Center with login activity, sessions, IP blocklist, and admin audit history (`28d0554` / `dd61c0a`)
- CSP violation reporting, security alerting, MFA status, and dependency health checks (`4bddecb` / `b221e33`)
- security scorecard improvements and deferred audit findings (`0fa0b59` / `f79c51e`)
- compliance tooling including consent mode, retention controls, and visitor-forget workflows (`a9f3355` / `513932c`)
- restored CSRF, CSV-injection, and rate-limit fixes plus stored-XSS/IP-spoofing hardening (`f539908`, `0041b90`, `93b97e7`, `50c0e19`)
- granular per-section permissions and 2FA enrollment (`b00531d` / `5aeae49`)

## Security corrections during the v3 line

The supplied history specifically records critical security work around:

- stored XSS in realtime dashboard output
- IP spoofing through forwarded headers
- CSRF on upload endpoints
- CSV formula injection
- rate limiting on the public event API

These corrections became part of the baseline that later v4 releases had to preserve.

## Position in the product evolution

v3.0.0 transformed Paxalia Dashboard into a broad operational analytics platform. v4 then concentrated on persistent observability, generic administration, and a hardened administrator authentication boundary built on top of this feature surface.
