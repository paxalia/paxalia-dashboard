# Paxalia Dashboard v1.0.0

## Release focus

**Paxalia Dashboard v1.0.0 — Privacy-first analytics foundation**

v1.0.0 is the first tagged release in the supplied repository history. It establishes the standalone Django analytics package that later versions expanded into the broader Paxalia operational platform.

## Repository milestones

The supplied history contains the following v1-era commits:

- `f522831` — initialize the standalone analytics package repository with Git configuration.
- `62e6fdc` — add the complete privacy-first analytics Django application.
- `2faa780` — add the README, Apache 2.0 license, `MANIFEST.in`, and `setup.cfg` packaging foundation.
- `a75d334` — complete the v1.0.0 release with billing import fixes, editable-install support, and README completion.

## Foundation established

The v1 line established the core identity that continues through current releases:

```text
Django application
        ↓
Paxalia analytics package
        ↓
application-owned analytics data
```

The package was designed to operate inside the Django application rather than depending on a hosted analytics collector as its primary architecture.

## Packaging and distribution

The release established the standalone package conventions that later releases retained:

- Python package metadata
- package data handling
- README-based long description
- Apache 2.0 licensing
- editable development installation support
- a dedicated Django application named `paxalia`

## Long-term significance

v1.0.0 is the starting point for the subsequent architecture. Later releases add capabilities around this analytics core rather than discarding it.
