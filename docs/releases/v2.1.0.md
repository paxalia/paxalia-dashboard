# Paxalia Dashboard v2.1.0

## Release focus

**Paxalia Dashboard v2.1.0 — API separation, CSP compliance, and package cleanup**

The supplied history identifies `602c4f2` as the v2.1.0 release commit.

## Repository milestone

- `602c4f2` — decouple the event API, complete CSP compliance, and perform package cleanup.

## API boundary

The release separated browser-facing analytics event behavior from other API concerns. That distinction remains important in the current package, where browser event ingestion and the authenticated Paxalia API have different trust models.

## Content Security Policy

v2.1.0 explicitly moved the package toward complete CSP compliance. Later releases continue this approach through nonce-aware and externally packaged browser assets rather than requiring a host application to weaken its CSP simply to use the dashboard.

## Package hygiene

The release also represents a packaging and structural cleanup milestone. Later version changes continue to treat distribution metadata, package data, and static assets as part of the product rather than as incidental build artifacts.
